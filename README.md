# ATHENE · Listening Node

Website for Team ATHENE (UAS detection at source): mission, the Listening Node, design-target specs with a 5 km × 5 km coverage planner, the team, and contact details.

It is a single static page (`index.html`) with its images beside it, so it runs on GitHub Pages with no build step.

## Publish with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Pick the **main** branch and the **/ (root)** folder, then **Save**.
4. After a minute the site is live at `https://philipsantiago.github.io/ATHENE/`.

Each section has its own link: `#mission`, `#product`, `#specs`, `#team` and `#contact`.

## Notes

- Specs are design targets, not measured results.
- The product image is a concept render, not a built prototype.
